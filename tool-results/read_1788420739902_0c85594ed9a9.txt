     1→"""
     2→ml/validation.py — Time-Series Walk-Forward Cross-Validation & Leakage Auditing.
     3→
     4→Three independent validation primitives for the ML prediction pipeline, plus a
     5→FastAPI route that exposes them over HTTP.
     6→
     7→  1. ``time_series_cv(model, X, y, n_splits=5, min_train_size=200)``
     8→     Expanding-window walk-forward CV. Fold ``k`` trains on ``[0 : t_k]`` and
     9→     validates on the next chunk ``[t_k : t_{k+1}]`` — i.e. the model is *always*
    10→     trained on strictly-prior observations and evaluated on the immediately
    11→     following chunk. Each fold retrains a fresh clone of the input model so
    12→     no fold's training state leaks into another fold's validation, and no
    13→     future information ever enters a training set (the cardinal sin for
    14→     time-series data). Returns per-fold + aggregate metrics (Brier, ROC-AUC,
    15→     log-loss, accuracy) plus a pooled out-of-sample metric across all folds.
    16→
    17→     When ``n`` is just above ``min_train_size`` the validation chunk
    18→     degenerates to a single sample (``val_size = 1``) — exactly the
    19→     ``train on [0:t], validate on [t:t+1]`` literal walk-forward described in
    20→     the task spec. When ``n`` is larger, ``val_size`` grows to
    21→     ``(n - min_train_size) // n_splits`` so each fold gets a statistically
    22→     meaningful validation chunk.
    23→
    24→  2. ``out_of_time_test(model, X_train, y_train, X_test, y_test)``
    25→     Temporal holdout: fit on the train split, evaluate on a temporally-later
    26→     test split. The test split must come from a *later* time period than the
    27→     train split — the caller is responsible for ordering (this module does
    28→     not re-sort). Returns the same metric suite + the raw prediction
    29→     probabilities (capped at 1000 rows) for downstream calibration analysis.
    30→
    31→  3. ``validate_no_leakage(features, labels)``
    32→     Static data-quality audit that flags common leakage / quality signals
    33→     *before* a model is trained:
    34→       - shape & length contract (features ↔ labels)
    35→       - NaN / Inf scan (per-matrix + per-feature)
    36→       - exact-duplicate feature vectors (suspicious if duplicates span a
    37→         train/test boundary — the caller should split *before* dedup)
    38→       - label-domain check (binary {0, 1} expected for this classifier)
    39→       - label-balance ratio (warns on severe imbalance)
    40→       - near-duplicate features with *conflicting* labels (the strongest
    41→         leakage signal — identical inputs producing different outputs means
    42→         hidden state is leaking through the features)
    43→     Returns ``{is_valid, issues, warnings, stats}``. ``issues`` are blocking
    44→     (``is_valid = False`` if any); ``warnings`` are advisory.
    45→
    46→Model contract
    47→--------------
    48→The validation functions accept any sklearn-style classifier:
    49→  - ``model.fit(X, y)`` trains it
    50→  - ``model.predict_proba(X)`` returns a 2-D array; column ``[:, 1]`` is taken
    51→    as the positive-class probability
    52→  - models with only ``predict(X)`` (e.g. a regressor returning probabilities)
    53→    are handled via a graceful fallback
    54→
    55→Each fold calls ``sklearn.base.clone(model)`` to get a fresh unfitted copy
    56→(works for any sklearn estimator). If clone fails (non-sklearn model), the
    57→function falls back to ``copy.deepcopy``; if that also fails, the original
    58→model is reused across folds and a warning is logged (state will leak between
    59→folds in that case — documented behaviour, not a silent failure).
    60→
    61→HTTP layer
    62→----------
    63→``api/server.py`` calls ``register_routes(app)`` at startup to expose:
    64→
    65→    POST /api/ml/validate
    66→        JSON body (``ValidationRequest``):
    67→            X                 : list[list[float]]  — feature matrix
    68→            y                 : list[int]           — binary labels {0, 1}
    69→            X_test?           : list[list[float]]   — required for validation_type='oot'
    70→            y_test?           : list[int]           — required for validation_type='oot'
    71→            validation_type   : 'cv' | 'oot' | 'both'   (default 'cv')
    72→            n_splits          : int (1..50, default 5)
    73→            min_train_size    : int (>=10, default 200)
    74→            model_class       : str — one of
    75→                                 {GradientBoostingClassifier (default),
    76→                                  RandomForestClassifier,
    77→                                  LogisticRegression,
    78→                                  SGDClassifier}
    79→            model_params?     : dict — kwargs passed to the model constructor
    80→            run_leakage_check?: bool (default True) — also run
    81→                                 validate_no_leakage and append the result
    82→        Returns: the CV and/or OOT result dict(s) + the leakage audit.
    83→        Auth-protected by the caller's existing fail-closed bearer middleware
    84→        (every route except /api/health requires ``Authorization: Bearer
    85→        <API_TOKEN>``).
    86→"""
    87→from __future__ import annotations
    88→
    89→import copy
    90→import logging
    91→import time
    92→from typing import Any
    93→
    94→import numpy as np
    95→from pydantic import BaseModel, Field
    96→from sklearn.ensemble import GradientBoostingClassifier, RandomForestClassifier
    97→from sklearn.linear_model import LogisticRegression, SGDClassifier
    98→from sklearn.metrics import accuracy_score, brier_score_loss, log_loss, roc_auc_score
    99→
   100→log = logging.getLogger(__name__)
   101→
   102→# ── Defaults & guards ───────────────────────────────────────────────────────
   103→DEFAULT_MODEL_CLASS = "GradientBoostingClassifier"
   104→DEFAULT_N_SPLITS = 5
   105→DEFAULT_MIN_TRAIN_SIZE = 200
   106→# Hard payload cap so a malicious / runaway caller cannot OOM the API by
   107→# POSTing a multi-GB feature matrix. 50k rows × 38 features ≈ 15 MB JSON —
   108→# well within FastAPI's default body limits but bounded.
   109→MAX_PAYLOAD_ROWS = 50_000
   110→# Cap on the number of raw predictions returned by out_of_time_test / the API
   111→# so the response stays tractable. The aggregate metrics are computed on the
   112→# full test set; only the raw ``predictions`` / ``actuals`` arrays are sliced.
   113→MAX_RAW_PREDICTIONS = 1_000
   114→# Nearest-duplicate conflict scan is O(n) via a hash but allocates one entry
   115→# per unique rounded row — skip it above this threshold to bound memory.
   116→NEAR_DUP_SCAN_ROW_LIMIT = 10_000
   117→# Rounding precision for the near-duplicate heuristic. 4 dp matches the
   118→# feature-pipeline's effective float32 precision (extract_features emits
   119→# float32 → ~7 significant digits → 4 dp after the decimal is conservative).
   120→NEAR_DUP_ROUND_DP = 4
   121→
   122→# Whitelist of sklearn classifiers the public API may instantiate. Kept tight
   123→# so a caller cannot construct arbitrary classes via the request body — only
   124→# the four estimators the production ensemble is built from are permitted.
   125→_MODEL_WHITELIST: dict[str, type] = {
   126→    "GradientBoostingClassifier": GradientBoostingClassifier,
   127→    "RandomForestClassifier": RandomForestClassifier,
   128→    "LogisticRegression": LogisticRegression,
   129→    "SGDClassifier": SGDClassifier,
   130→}
   131→
   132→# Random seed applied to every whitelisted estimator that accepts one — makes
   133→# CV results reproducible across runs for the same (X, y) + model_class.
   134→_SEED = 42
   135→
   136→

   141→class ValidationRequest(BaseModel):

   148→    y: list[int] = Field(

   150→        description="Binary labels in {0, 1}; same length as X.",

   152→    X_test: list[list[float]] | None = Field(

   154→        description=(
   155→            "Out-of-time test features — required when validation_type is "
   156→            "'oot' or 'both'. Must have the same feature dimensionality as X."

   158→    )
   159→    y_test: list[int] | None = Field(
   160→        None,
   161→        description="Out-of-time test labels — required with X_test.",

   163→    validation_type: str = Field(

   165→        description="One of 'cv' (walk-forward), 'oot' (out-of-time), or 'both'.",
   166→    )
   167→    n_splits: int = Field(
   168→        DEFAULT_N_SPLITS,
   169→        ge=1,
   170→        le=50,
   171→        description="Number of walk-forward folds (validation_type='cv' / 'both').",
   172→    )
   173→    min_train_size: int = Field(
   174→        DEFAULT_MIN_TRAIN_SIZE,

   185→    model_params: dict[str, Any] | None = Field(

   187→        description="Optional kwargs passed to the model constructor (e.g. learning_rate).",

   189→    run_leakage_check: bool = Field(
   190→        True,
   191→        description="Also run validate_no_leakage(features, labels) and append the result.",
   192→    )

   198→def _fresh_model(model: Any) -> Any:
   199→    """Return a fresh, unfitted copy of ``model`` for this CV fold.
   200→
   201→    Tries ``sklearn.base.clone`` (works for any sklearn estimator — resets
   202→    fitted state without copying data). If clone fails (non-sklearn model or
   203→    a custom estimator without ``get_params``), falls back to
   204→    ``copy.deepcopy``. If both fail (e.g. model contains an unpicklable
   205→    handle), returns the original model — in which case state WILL leak
   206→    between folds (logged at WARNING so it is never a silent failure).
   207→    """
   208→    try:
   209→        return clone(model)
   210→    except Exception:
   211→        pass
   212→    try:
   213→        return copy.deepcopy(model)
   214→    except Exception:
   215→        log.warning(
   216→            "[validation] cannot clone or deepcopy model %r — reusing the "
   217→            "same instance across folds (fold state will leak between folds)",
   218→            type(model).__name__,
   219→        )
   220→        return model
   221→
   222→
   223→def _predict_proba(model: Any, X: np.ndarray) -> np.ndarray:
   224→    """Return the positive-class probability vector for ``X``.
   225→
   226→    Prefers ``model.predict_proba`` (sklearn API); takes column ``[:, 1]``
   227→    for 2-D outputs. Falls back to ``model.predict`` for regressor-style
   228→    estimators that emit probabilities directly. Raises ``TypeError`` if
   229→    neither method exists.
   230→    """
   231→    if hasattr(model, "predict_proba"):
   232→        proba = model.predict_proba(X)
   233→        arr = np.asarray(proba, dtype=np.float64)
   234→        if arr.ndim == 2 and arr.shape[1] >= 2:
   235→            return arr[:, 1]
   236→        return arr.ravel()
   237→    if hasattr(model, "predict"):
   238→        return np.asarray(model.predict(X), dtype=np.float64).ravel()
   239→    raise TypeError(
   240→        f"Model {type(model).__name__} exposes neither predict_proba nor predict"
   241→    )
   242→

   244→def _classification_metrics(y_true: np.ndarray, y_prob: np.ndarray) -> dict[str, Any]:
   245→    """Compute the canonical binary-classification metric suite.
   246→
   247→    All metrics degrade gracefully to ``None`` when undefined for the given
   248→    (y_true, y_prob) — e.g. AUC is ``None`` when only one class is present in
   249→    ``y_true``. Never raises.
   250→    """
   251→    y_true = np.asarray(y_true, dtype=np.int64).ravel()
   252→    y_prob = np.asarray(y_prob, dtype=np.float64).ravel()
   253→    n = int(y_true.shape[0])
   254→    out: dict[str, Any] = {
   255→        "n_samples": n,
   256→        "mean_pred": round(float(np.mean(y_prob)), 6) if n else 0.0,
   257→        "mean_actual": round(float(np.mean(y_true)), 6) if n else 0.0,
   258→    }
   259→    if n == 0:
   260→        out.update({"brier": None, "auc": None, "log_loss": None, "accuracy": None})
   261→        return out
   262→    # Brier is defined for any binary y + probs in [0, 1].
   263→    try:
   264→        out["brier"] = round(float(brier_score_loss(y_true, y_prob)), 6)
   265→    except Exception as e:  # pragma: no cover — defensive
   266→        log.debug("[validation] brier_score_loss failed: %s", e)
   267→        out["brier"] = None
   268→    # AUC requires both classes present.
   269→    if len(np.unique(y_true)) >= 2:
   270→        try:
   271→            out["auc"] = round(float(roc_auc_score(y_true, y_prob)), 6)
   272→        except Exception as e:  # pragma: no cover — defensive
   273→            log.debug("[validation] roc_auc_score failed: %s", e)
   274→            out["auc"] = None
   275→    else:
   276→        out["auc"] = None
   277→    # log_loss needs the prob clipped away from {0, 1} to avoid log(0).
   278→    try:
   279→        p_clip = np.clip(y_prob, 1e-10, 1.0 - 1e-10)
   280→        out["log_loss"] = round(float(log_loss(y_true, p_clip, labels=[0, 1])), 6)
   281→    except Exception as e:  # pragma: no cover — defensive
   282→        log.debug("[validation] log_loss failed: %s", e)
   283→        out["log_loss"] = None
   284→    # Accuracy at the canonical 0.5 threshold.
   285→    try:
   286→        y_pred = (y_prob >= 0.5).astype(np.int64)
   287→        out["accuracy"] = round(float(accuracy_score(y_true, y_pred)), 6)
   288→    except Exception as e:  # pragma: no cover — defensive
   289→        log.debug("[validation] accuracy_score failed: %s", e)
   290→        out["accuracy"] = None
   291→    return out
   292→
   293→
   294→def _aggregate_metrics(
   295→    per_fold: list[dict[str, Any]],
   296→    pooled_y_true: np.ndarray,
   297→    pooled_y_prob: np.ndarray,
   298→) -> dict[str, Any]:
   299→    """Roll up per-fold metrics into mean/std summaries + a pooled OOS metric.
   300→
   301→    The pooled metric concatenates every fold's out-of-sample predictions
   302→    and recomputes the suite once — this is the single-number headline metric
   303→    that's most resistant to per-fold noise (a fold with 1 sample has a
   304→    degenerate per-fold AUC; the pooled AUC over all folds is meaningful).
   305→    """
   306→    briers = [f["brier"] for f in per_fold if f.get("brier") is not None]
   307→    aucs = [f["auc"] for f in per_fold if f.get("auc") is not None]
   308→    lls = [f["log_loss"] for f in per_fold if f.get("log_loss") is not None]
   309→    accs = [f["accuracy"] for f in per_fold if f.get("accuracy") is not None]
   310→
   311→    pooled = (
   312→        _classification_metrics(pooled_y_true, pooled_y_prob)
   313→        if pooled_y_true.size
   314→        else {}
   315→    )
   316→
   317→    def _mean(vals: list[float]) -> float | None:
   318→        return round(float(np.mean(vals)), 6) if vals else None
   319→
   320→    def _std(vals: list[float]) -> float | None:
   321→        return round(float(np.std(vals, ddof=0)), 6) if vals else None
   322→
   323→    return {
   324→        "n_folds_evaluated": len(per_fold),
   325→        "mean_brier": _mean(briers),
   326→        "std_brier": _std(briers),
   327→        "mean_auc": _mean(aucs),
   328→        "std_auc": _std(aucs),
   329→        "mean_log_loss": _mean(lls),
   330→        "mean_accuracy": _mean(accs),
   331→        "total_train_samples": int(sum(f["train_size"] for f in per_fold)),
   332→        "total_val_samples": int(sum(f["val_size"] for f in per_fold)),
   333→        "pooled": pooled,
   334→    }
   335→
   336→
   337→def _build_model(cls_name: str, params: dict[str, Any]) -> Any:
   338→    """Instantiate a whitelisted sklearn classifier with sensible defaults.
   339→
   340→    The defaults ensure every model exposes ``predict_proba`` and is
   341→    deterministic (``random_state=42``) so the same (X, y) + model_class
   342→    yields identical metrics across runs — critical for reproducible
   343→    validation reports.
   344→    """
   345→    if cls_name not in _MODEL_WHITELIST:
   346→        raise ValueError(
   347→            f"model_class {cls_name!r} not in whitelist: {sorted(_MODEL_WHITELIST)}"
   348→        )
   349→    cls = _MODEL_WHITELIST[cls_name]
   350→    p = dict(params or {})
   351→    # Per-class defaults — only set if the caller didn't override.
   352→    if cls_name == "SGDClassifier":
   353→        # log_loss → has predict_proba; default loss ('hinge') does not.
   354→        p.setdefault("loss", "log_loss")
   355→        p.setdefault("eta0", 0.01)
   356→        p.setdefault("max_iter", 5)
   357→        p.setdefault("tol", 1e-3)
   358→        p.setdefault("random_state", _SEED)
   359→    elif cls_name == "LogisticRegression":
   360→        p.setdefault("max_iter", 1000)
   361→        p.setdefault("random_state", _SEED)
   362→    elif cls_name in ("GradientBoostingClassifier", "RandomForestClassifier"):
   363→        p.setdefault("random_state", _SEED)
   364→    return cls(**p)

   369→
   370→def time_series_cv(
   371→    model: Any,
   372→    X: Any,
   373→    y: Any,
   374→    n_splits: int = DEFAULT_N_SPLITS,
   375→    min_train_size: int = DEFAULT_MIN_TRAIN_SIZE,
   376→) -> dict[str, Any]:
   377→    """Expanding-window walk-forward cross-validation.
   378→
   379→    Fold ``k`` (0-indexed) trains on ``X[0 : t_k]`` (``t_k = min_train_size +
   380→    k * val_size``) and validates on ``X[t_k : t_k + val_size]``. Each fold
   381→    retrains a fresh clone of ``model`` so no fold's fitted state leaks into
   382→    another fold's evaluation. ``val_size = max(1, (n - min_train_size) //
   383→    n_splits)`` — when ``n`` is close to ``min_train_size`` this degenerates
   384→    to a single-sample validation fold (the literal ``[t:t+1]`` walk-forward).
   385→
   386→    Args:
   387→        model: any sklearn-style classifier (``.fit`` + ``.predict_proba``).
   388→        X: 2-D feature matrix (list-of-lists or ndarray).
   389→        y: 1-D integer label vector in {0, 1}.
   390→        n_splits: number of walk-forward folds (>= 1).
   391→        min_train_size: minimum training-window size for fold 0 (>= 1).
   392→
   393→    Returns:
   394→        ``{n_splits, min_train_size, total_samples, val_size, per_fold, aggregate}``.
   395→        ``per_fold`` is a list of per-fold metric dicts; ``aggregate`` is the
   396→        mean/std roll-up + a pooled out-of-sample metric across all folds.
   397→
   398→    Raises:
   399→        ValueError: if ``X``/``y`` shapes mismatch or there isn't enough data
   400→            for the requested ``n_splits`` + ``min_train_size``.
   401→    """
   402→    X_arr = np.asarray(X, dtype=np.float64)
   403→    y_arr = np.asarray(y, dtype=np.int64).ravel()
   404→    if X_arr.ndim != 2:
   405→        raise ValueError(f"X must be 2-D, got shape {X_arr.shape}")
   406→    n = int(X_arr.shape[0])
   407→    if y_arr.shape[0] != n:
   408→        raise ValueError(
   409→            f"X/y length mismatch: X has {n} rows, y has {y_arr.shape[0]}"
   410→        )
   411→    n_splits = max(1, int(n_splits))
   412→    min_train_size = max(1, int(min_train_size))
   413→    # Need at least min_train_size + 1 sample to do a single fold (train on
   414→    # min_train_size, validate on >= 1). Each additional fold needs val_size
   415→    # more samples.
   416→    if n < min_train_size + 1:
   417→        raise ValueError(
   418→            f"need at least min_train_size + 1 = {min_train_size + 1} samples "
   419→            f"for one walk-forward fold, got {n}"
   420→        )
   421→    val_size = max(1, (n - min_train_size) // n_splits)
   422→
   423→    per_fold: list[dict[str, Any]] = []
   424→    pooled_y_true: list[np.ndarray] = []
   425→    pooled_y_prob: list[np.ndarray] = []
   426→
   427→    for k in range(n_splits):
   428→        train_end = min_train_size + k * val_size
   429→        val_start = train_end
   430→        if val_start >= n:
   431→            # Ran out of data — fewer folds than requested.
   432→            log.debug(
   433→                "[validation] walk-forward fold %d skipped: val_start=%d >= n=%d",
   434→                k, val_start, n,
   435→            )
   436→            break
   437→        val_end = min(val_start + val_size, n)
   438→        X_tr, y_tr = X_arr[:train_end], y_arr[:train_end]
   439→        X_va, y_va = X_arr[val_start:val_end], y_arr[val_start:val_end]
   440→
   441→        fold_model = _fresh_model(model)
   442→        fold_model.fit(X_tr, y_tr)
   443→        y_prob = _predict_proba(fold_model, X_va)
   444→        m = _classification_metrics(y_va, y_prob)
   445→        m.update({
   446→            "fold": k,
   447→            "train_size": int(train_end),
   448→            "val_size": int(val_end - val_start),
   449→            "train_end_index": int(train_end),
   450→            "val_start_index": int(val_start),
   451→            "val_end_index": int(val_end),
   452→        })
   453→        per_fold.append(m)
   454→        pooled_y_true.append(np.asarray(y_va, dtype=np.int64))
   455→        pooled_y_prob.append(np.asarray(y_prob, dtype=np.float64))
   456→
   457→    if not per_fold:
   458→        raise ValueError(
   459→            f"no walk-forward folds could be produced from n={n} samples "
   460→            f"with min_train_size={min_train_size}"
   461→        )
   462→
   463→    y_concat = (
   464→        np.concatenate(pooled_y_true) if pooled_y_true else np.array([], dtype=np.int64)
   465→    )
   466→    p_concat = (
   467→        np.concatenate(pooled_y_prob) if pooled_y_prob else np.array([], dtype=np.float64)
   468→    )
   469→    aggregate = _aggregate_metrics(per_fold, y_concat, p_concat)
   470→
   471→    return {
   472→        "method": "walk_forward_expanding_window",
   473→        "n_splits_requested": n_splits,
   474→        "n_splits_evaluated": len(per_fold),
   475→        "min_train_size": min_train_size,
   476→        "val_size": val_size,
   477→        "total_samples": n,
   478→        "per_fold": per_fold,
   479→        "aggregate": aggregate,
   480→    }

   483→def out_of_time_test(
   484→    model: Any,
   485→    X_train: Any,
   486→    y_train: Any,
   487→    X_test: Any,
   488→    y_test: Any,
   489→) -> dict[str, Any]:
   490→    """Train on ``(X_train, y_train)``, evaluate on a temporally-later test set.
   491→
   492→    Out-of-time validation: the test split must come from a *later* time
   493→    period than the train split. This module does not re-sort — the caller
   494→    is responsible for temporal ordering. The test split is never shuffled
   495→    or mixed into training.
   496→
   497→    Args:
   498→        model: sklearn-style classifier (``.fit`` + ``.predict_proba``).
   499→        X_train, y_train: training split (2-D features + 1-D labels).
   500→        X_test, y_test: temporally-later test split.
   501→
   502→    Returns:
   503→        ``{metrics, predictions, actuals}`` where ``metrics`` is the
   504→        classification-metric suite (Brier / AUC / log-loss / accuracy /
   505→        n_samples / mean_pred / mean_actual + split sizes) and
   506→        ``predictions`` / ``actuals`` are the raw per-row probabilities /
   507→        labels capped at ``MAX_RAW_PREDICTIONS`` rows for response tractability.
   508→    """
   509→    X_tr = np.asarray(X_train, dtype=np.float64)
   510→    y_tr = np.asarray(y_train, dtype=np.int64).ravel()
   511→    X_te = np.asarray(X_test, dtype=np.float64)
   512→    y_te = np.asarray(y_test, dtype=np.int64).ravel()
   513→    if X_tr.ndim != 2 or X_te.ndim != 2:
   514→        raise ValueError(
   515→            f"X_train and X_test must be 2-D; got {X_tr.shape} and {X_te.shape}"
   516→        )
   517→    if X_tr.shape[0] != y_tr.shape[0]:
   518→        raise ValueError(
   519→            f"train length mismatch: X={X_tr.shape[0]} y={y_tr.shape[0]}"
   520→        )
   521→    if X_te.shape[0] != y_te.shape[0]:
   522→        raise ValueError(
   523→            f"test length mismatch: X={X_te.shape[0]} y={y_te.shape[0]}"
   524→        )
   525→    if X_tr.shape[1] != X_te.shape[1]:
   526→        raise ValueError(
   527→            f"feature-dim mismatch: train={X_tr.shape[1]} test={X_te.shape[1]}"
   528→        )
   529→    fresh = _fresh_model(model)
   530→    fresh.fit(X_tr, y_tr)
   531→    y_prob = _predict_proba(fresh, X_te)
   532→    metrics = _classification_metrics(y_te, y_prob)
   533→    metrics.update({
   534→        "train_size": int(X_tr.shape[0]),
   535→        "test_size": int(X_te.shape[0]),
   536→        "n_features": int(X_tr.shape[1]),
   537→    })
   538→    return {
   539→        "method": "out_of_time_holdout",
   540→        "metrics": metrics,
   541→        # Clip probabilities to [0, 1] defensively (some sklearn paths can
   542→        # emit tiny negatives / >1 under numerical edge cases) before exposing.
   543→        "predictions": np.clip(y_prob, 0.0, 1.0).tolist()[:MAX_RAW_PREDICTIONS],
   544→        "actuals": y_te.tolist()[:MAX_RAW_PREDICTIONS],
   545→        "predictions_truncated": bool(len(y_prob) > MAX_RAW_PREDICTIONS),
   546→    }

   549→def validate_no_leakage(features: Any, labels: Any) -> dict[str, Any]:
   550→    """Audit ``(features, labels)`` for common data-leakage / quality issues.
   551→
   552→    Static checks (no model is trained):
   553→      - shape & length contract (features ↔ labels)
   554→      - NaN / Inf scan (whole-matrix + per-feature counts)
   555→      - exact-duplicate feature vectors (suspicious if duplicates span a
   556→        train/test boundary — the caller should split *before* dedup)
   557→      - label-domain check (binary {0, 1} expected for this classifier)
   558→      - label-balance ratio (warns on severe imbalance < 0.1)
   559→      - near-duplicate features with *conflicting* labels — the strongest
   560→        leakage signal: identical inputs producing different outputs means
   561→        hidden state is leaking through the features. Uses a rounded-hash
   562→        heuristic (O(n), skips for n > ``NEAR_DUP_SCAN_ROW_LIMIT``).
   563→
   564→    Returns:
   565→        ``{is_valid, n_samples, n_features, issues, warnings, stats}``.
   566→        ``issues`` are blocking (``is_valid = False`` if non-empty);
   567→        ``warnings`` are advisory.
   568→    """
   569→    issues: list[str] = []
   570→    warnings: list[str] = []
   571→
   572→    X = np.asarray(features, dtype=np.float64)
   573→    y = np.asarray(labels)
   574→
   575→    # ── Shape contract ──────────────────────────────────────────────────
   576→    if X.ndim != 2:
   577→        issues.append(f"features must be 2-D, got shape {X.shape}")
   578→        # Best-effort reshape so the rest of the function can run.
   579→        X = (
   580→            X.reshape(-1, 1)
   581→            if X.size
   582→            else np.zeros((0, 1), dtype=np.float64)
   583→        )
   584→    n, d = int(X.shape[0]), int(X.shape[1])
   585→
   586→    if y.ndim != 1:
   587→        y = y.ravel()
   588→    if y.shape[0] != n:
   589→        issues.append(
   590→            f"length mismatch: features has {n} rows, labels has {y.shape[0]}"
   591→        )
   592→
   593→    # ── NaN / Inf scan ───────────────────────────────────────────────────
   594→    n_nan = int(np.isnan(X).sum()) if n else 0
   595→    n_inf = int(np.isinf(X).sum()) if n else 0
   596→    if n_nan:
   597→        warnings.append(f"features contain {n_nan} NaN values — will be treated as 0.0 by most sklearn estimators")
   598→    if n_inf:
   599→        warnings.append(f"features contain {n_inf} Inf values — will break most sklearn estimators")
   600→
   601→    per_feature_nan: dict[str, int] = {}
   602→    if n and d and n_nan:
   603→        col_nan = np.isnan(X).sum(axis=0)
   604→        for idx in np.where(col_nan > 0)[0]:
   605→            per_feature_nan[str(int(idx))] = int(col_nan[idx])
   606→
   607→    # ── Label domain ─────────────────────────────────────────────────────
   608→    unique_labels = sorted({int(v) for v in y.tolist()}) if n else []
   609→    if unique_labels and not set(unique_labels).issubset({0, 1}):
   610→        issues.append(
   611→            f"labels must be binary {{0, 1}} for this classifier; "
   612→            f"got unique={unique_labels[:10]}"
   613→        )
   614→
   615→    # ── Exact-duplicate feature vectors ─────────────────────────────────
   616→    n_dup = 0
   617→    if n > 0:
   618→        seen: set[bytes] = set()
   619→        for row in X:
   620→            key = row.tobytes()
   621→            if key in seen:
   622→                n_dup += 1
   623→            else:
   624→                seen.add(key)
   625→    if n_dup:
   626→        ratio = n_dup / n if n else 0.0
   627→        warnings.append(
   628→            f"{n_dup} duplicate feature vectors ({ratio:.2%} of {n}) — "
   629→            f"possible leakage if duplicates span a train/test boundary "
   630→            f"(split BEFORE dedup to be safe)"
   631→        )
   632→
   633→    # ── Label balance ────────────────────────────────────────────────────
   634→    label_dist: dict[str, int] = {}
   635→    if n:
   636→        values, counts = np.unique(y, return_counts=True)
   637→        label_dist = {str(int(v)): int(c) for v, c in zip(values, counts)}
   638→    balance_ratio: float | None = None
   639→    if len(label_dist) >= 2:
   640→        counts = list(label_dist.values())
   641→        balance_ratio = min(counts) / max(counts)
   642→        if balance_ratio < 0.1:
   643→            warnings.append(
   644→                f"severe label imbalance: balance_ratio={balance_ratio:.3f} "
   645→                f"({label_dist}) — minority class may be under-learned"
   646→            )
   647→    elif len(label_dist) == 1:
   648→        warnings.append(f"only one label class present: {label_dist} — AUC / log-loss undefined")
   649→
   650→    # ── Near-duplicate features with conflicting labels ─────────────────
   651→    # The strongest leakage signal: identical (to 4dp) feature vectors
   652→    # producing different labels. Genuine identical inputs should always map
   653→    # to the same label — a conflict means hidden state (timestamp, ID,
   654→    # future leakage) is determining the outcome.
   655→    near_dup_conflicts = 0
   656→    if 0 < n <= NEAR_DUP_SCAN_ROW_LIMIT and d > 0:
   657→        rounded = np.round(X, NEAR_DUP_ROUND_DP)
   658→        first_label_for_row: dict[bytes, int] = {}
   659→        for i in range(n):
   660→            key = rounded[i].tobytes()
   661→            if key in first_label_for_row:
   662→                if int(y[i]) != first_label_for_row[key]:
   663→                    near_dup_conflicts += 1
   664→            else:
   665→                first_label_for_row[key] = int(y[i])
   666→        if near_dup_conflicts:
   667→            issues.append(
   668→                f"{near_dup_conflicts} near-duplicate feature vectors (rounded "
   669→                f"to {NEAR_DUP_ROUND_DP}dp) with CONFLICTING labels — strongest "
   670→                f"leakage signal: identical inputs producing different outputs "
   671→                f"means hidden state is leaking through the features"
   672→            )
   673→    elif n > NEAR_DUP_SCAN_ROW_LIMIT:
   674→        warnings.append(
   675→            f"near-duplicate conflict scan skipped: n={n} > limit "
   676→            f"{NEAR_DUP_SCAN_ROW_LIMIT} (O(n) hash scan; re-run on a sample "
   677→            f"to check for leakage signals)"
   678→        )
   679→
   680→    is_valid = len(issues) == 0
   681→    return {
   682→        "is_valid": is_valid,
   683→        "n_samples": n,
   684→        "n_features": d,
   685→        "issues": issues,
   686→        "warnings": warnings,
   687→        "stats": {
   688→            "n_nan": n_nan,
   689→            "n_inf": n_inf,
   690→            "n_duplicate_rows": n_dup,
   691→            "n_near_dup_label_conflicts": near_dup_conflicts,
   692→            "label_distribution": label_dist,
   693→            "label_balance_ratio": (
   694→                round(float(balance_ratio), 6) if balance_ratio is not None else None
   695→            ),
   696→            "per_feature_nan_counts": per_feature_nan,
   697→        },
   698→    }

   704→def register_routes(app: Any) -> None:
   705→    """Append ``POST /api/ml/validate`` to a FastAPI app.
   706→
   707→    Endpoint (auth-protected by the caller's existing fail-closed bearer
   708→    middleware — every route except ``/api/health`` requires
   709→    ``Authorization: Bearer <API_TOKEN>``):
   710→
   711→      POST /api/ml/validate
   712→          Body: ``ValidationRequest`` (see the model for field docs).
   713→          Returns:
   714→            {
   715→              "model_class": <str>,
   716→              "model_params": <dict>,
   717→              "n_samples": <int>,
   718→              "n_features": <int>,
   719→              "validation_type": <'cv'|'oot'|'both'>,
   720→              "generated_at": <epoch float>,
   721→              "leakage_check": <validate_no_leakage result>,  # if run
   722→              "cv": <time_series_cv result>,                 # if cv/both
   723→              "oot": <out_of_time_test result>,               # if oot/both
   724→            }
   725→    """
   726→    # Lazy import — FastAPI is optional at module load (keeps the module
   727→    # importable in environments that only need the pure-Python validation
   728→    # primitives, e.g. unit tests / notebooks without the API server).
   729→    from fastapi import HTTPException
   730→
   731→    @app.post("/api/ml/validate", tags=["ml-validation"])
   732→    async def _ml_validate(req: ValidationRequest):
   733→        """Run walk-forward CV and/or out-of-time validation on the posted data."""
   734→        n_rows = len(req.X)
   735→        if n_rows > MAX_PAYLOAD_ROWS:
   736→            raise HTTPException(
   737→                413,
   738→                f"payload too large: {n_rows} rows > {MAX_PAYLOAD_ROWS} max",
   739→            )
   740→
   741→        # ── Build the model ──────────────────────────────────────────────
   742→        cls_name = req.model_class or DEFAULT_MODEL_CLASS
   743→        if cls_name not in _MODEL_WHITELIST:
   744→            raise HTTPException(
   745→                400,
   746→                f"model_class {cls_name!r} not in whitelist: "
   747→                f"{sorted(_MODEL_WHITELIST)}",
   748→            )
   749→        params = dict(req.model_params or {})
   750→        try:
   751→            model = _build_model(cls_name, params)
   752→        except TypeError as e:
   753→            # Bad kwarg for the chosen estimator.
   754→            raise HTTPException(400, f"model_params rejected by {cls_name}: {e}")
   755→
   756→        # ── Coerce inputs to numpy once ──────────────────────────────────
   757→        X = np.asarray(req.X, dtype=np.float64)
   758→        y = np.asarray(req.y, dtype=np.int64).ravel()
   759→        if X.ndim != 2:
   760→            raise HTTPException(400, f"X must be 2-D, got shape {X.shape}")
   761→        if X.shape[0] != y.shape[0]:
   762→            raise HTTPException(
   763→                400,
   764→                f"X/y length mismatch: X={X.shape[0]} y={y.shape[0]}",
   765→            )
   766→
   767→        response: dict[str, Any] = {
   768→            "model_class": cls_name,
   769→            "model_params": params,
   770→            "n_samples": int(X.shape[0]),
   771→            "n_features": int(X.shape[1]),
   772→            "validation_type": req.validation_type,
   773→            "generated_at": time.time(),
   774→        }
   775→
   776→        # ── Leakage audit (always-on unless explicitly disabled) ────────
   777→        if req.run_leakage_check:
   778→            response["leakage_check"] = validate_no_leakage(X, y)
   779→
   780→        # ── Run the requested validation(s) ─────────────────────────────
   781→        try:
   782→            if req.validation_type in ("cv", "both"):
   783→                response["cv"] = time_series_cv(
   784→                    model,
   785→                    X,
   786→                    y,
   787→                    n_splits=req.n_splits,
   788→                    min_train_size=req.min_train_size,
   789→                )
   790→            if req.validation_type in ("oot", "both"):
   791→                if req.X_test is None or req.y_test is None:
   792→                    raise HTTPException(
   793→                        400,
   794→                        "validation_type='oot'/'both' requires X_test and y_test",
   795→                    )
   796→                response["oot"] = out_of_time_test(
   797→                    model, X, y, req.X_test, req.y_test
   798→                )
   799→            if req.validation_type not in ("cv", "oot", "both"):
   800→                raise HTTPException(
   801→                    400,
   802→                    f"validation_type must be 'cv', 'oot', or 'both'; "
   803→                    f"got {req.validation_type!r}",
   804→                )
   805→        except HTTPException:
   806→            raise
   807→        except ValueError as e:
   808→            raise HTTPException(400, str(e))
   809→        except Exception as e:  # pragma: no cover — defensive last net
   810→            log.error("[ml_validation] /api/ml/validate failed: %s", e, exc_info=True)
   811→            raise HTTPException(500, f"validation failed: {e}")
   812→
   813→        return response
